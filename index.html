How to Deploy and Keep Site Updated

This static download site is fully optimized to run on **GitHub Pages**. To host it, follow these simple steps:

  1. Ensure this website code (`index.html`, `style.css`, `app.js`, `files-data.js`) is pushed to your main branch on GitHub.
  2. Go to your GitHub Repository -> Settings -> Pages.
  3. Under Build and deployment, select Deploy from a branch. Select the main branch and folder / (root), then click Save.
  4. GitHub will deploy your website to: https://<your-username>.github.io/<repo-name>/

To update the download list after adding or deleting files:

Simply run the Node.js script in your workspace terminal before pushing code:

node update-index.js
